Guide

Bulk Actions Hub for Zoho Desk · Last updated: 2 October 2026

1. Install and authorize

Install from Zoho Marketplace, choose the departments and profiles that may use it, then authorize the Zoho Desk connection when asked. The extension appears as a Bulk Actions Hub tab in the top bar (it may sit under the “more” menu if you have many tabs).

2. Find tickets

Choose a department and any of: a Zoho Desk view, status, priority, assignee, channel, created date range. These read live data. Tag and Subject contains use Zoho search, which returns up to 5,000 tickets and can lag a few minutes behind very recent changes. Untick any ticket you want to leave out.

3. Choose changes

  • Field changes: status, priority, classification, category, assignee and custom fields (pick-list, text, number, date, checkbox). Leave a value empty to clear it.
  • Tags: add and/or remove, comma separated.
  • Move to department: runs last, after the other changes.
  • Email reply: choose the From address and write the message. Placeholders: {{contact.firstName}}, {{contact.lastName}}, {{contact.name}}, {{contact.email}}, {{ticket.number}}, {{ticket.subject}}, {{ticket.status}}, {{agent.name}}, {{department.name}}. Add a fallback after a bar: {{contact.firstName|there}}. Tickets without a contact email are skipped. You can set the status after the reply.

4. Preview and apply

The preview lists every ticket with old → new values, skips tickets that already match, shows a sample reply and estimates API calls, credits and time. Download the undo file here. Above 20 tickets, type APPLY to confirm. Keep the tab open while it runs; you can pause or stop.

5. Undo

Revert this run sets fields, tags and departments back to their previous values. Later, use Restore from file with the result file. Sent emails cannot be unsent, and if someone changed a ticket after your run, restoring overwrites their newer value for those fields.

Presets and history

Save the current changes (and optionally the filters) as a preset; presets are shared with everyone in the portal who uses the extension. Find & preview runs the filters and builds the preview — it never applies without your confirmation. History lists who ran what, when and how many tickets changed; ticket contents are not stored.

Admin settings

  • Allow changes (on by default): turn off to keep finding, previewing and exporting while blocking every change.
  • Allow bulk replies (on by default).
  • Max tickets per run: 1 to 5,000, default 2,000.

Limits and API credits

  • Field changes use Zoho's “update many” endpoint: 50 tickets per call, 1 credit per 2 tickets. Clearing a value and some fields fall back to one call per ticket.
  • Tags, replies and department moves are one call per ticket (1 credit each).
  • The extension sends at most 40 requests per minute, one at a time, to stay inside Zoho's limits. 1,000 tickets with a tag change take about 25 minutes.
  • Closing tickets may email customers if closure notifications are on in your Zoho Desk — try one ticket first.
  • Archived tickets are not supported (Zoho Desk does not allow bulk actions there either).
