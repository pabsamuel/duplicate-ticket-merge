Support

Email support@atesensoftware.com. We answer within 1 business day (Turkey time, UTC+3). Please include your Zoho Desk data center (com, eu, in, …), what you tried and a screenshot. Never send passwords or API tokens.

Common questions

The Bulk Actions Hub tab is missing

Check the “more” menu at the end of the top bar. Your profile must be among those selected at installation.

“The extension's connection needs to be authorized again”

Go to Setup → Marketplace → Installed extensions → Bulk Actions Hub → Connections and authorize Zoho Desk.

A ticket I just changed still shows in a tag or subject search

Zoho search can lag a few minutes. Filters without tag/subject read live data.

“Your Zoho Desk daily API credits are used up”

Credits reset every 24 hours. The preview shows the credits a run will use; split very large runs over two days.

The download didn't save

Use “Show CSV” and “Copy CSV”, then paste into a text file saved as .csv.
